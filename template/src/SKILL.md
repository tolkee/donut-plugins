# Hello

A small demo plugin that greets people and keeps a count of greetings.

- To greet someone, call `hello__greet` with their name and say the greeting aloud. It opens the
  `hello.card` window when the user wants to see it.
- `hello__remember` saves a greeting to the plugin's notes. It waits for the user's yes: say the name
  you're saving, then stop.
- The quote in the card comes from api.github.com: read it aloud only when asked.
